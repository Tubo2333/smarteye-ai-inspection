# IPC-A-610 电子组件可接受性标准（公开摘要）

> 声明: 本文基于 IPC-A-610 公开培训材料和学术论文中的引用整理，仅供学习参考。
> 完整标准请购买 IPC 官方出版物 (www.ipc.org)。

## §3 焊接可接受标准

### 3.1 片式元件焊接
- 焊点应呈现光滑、光亮的外观，无明显空洞、裂纹或桥接
- 焊料应充分润湿焊盘和元件端子
- 侧面偏移: 片式元件侧面偏移不应超过元件宽度的 25%
- 端部偏移: 元件端子超出焊盘端部不允许

### 3.2 BGA/CSP 焊接空洞
- Class 1 (通用电子产品): 单个焊球空洞率 ≤ 30%
- Class 2 (专用服务电子产品): 单个焊球空洞率 ≤ 25%
- Class 3 (高可靠性/汽车电子/医疗): 单个焊球空洞率 ≤ 15%
- 空洞率按 X-Ray 图像中空洞面积占焊球投影面积百分比计算
- 相邻多个焊球同时出现 >20% 空洞需额外评估

### 3.3 焊点外观
- 焊点表面应平滑，无尖锐突起
- 允许轻微的不均匀，但不允许裂纹、针孔 (>0.1mm) 或明显的氧化变色
- 焊料应覆盖焊盘面积的 75% 以上 (Class 2)

## §5 元件安装

### 5.1 片式元件
- 元件应居中放置在焊盘上
- 侧面偏移: ≤ 元件宽度 25% (Class 2), ≤ 15% (Class 3)
- 端部偏移: 端子必须完全在焊盘上

### 5.2 IC/QFP 封装
- 引脚偏移: ≤ 引脚宽度 25% (Class 2)
- 引脚共面性: 所有引脚应与焊盘接触或有 ≤ 0.1mm 间距
- 桥接: 相邻引脚间不允许任何桥接

## §8 表面贴装缺陷判定

### 8.1 桥接 (Bridge/Short)
- 定义: 相邻导体间出现非预期的焊料连接
- 判定: 任何桥接均为缺陷 (所有 Class)
- Class 3: 零容忍，发现即判退

### 8.2 开路 (Open)
- 定义: 焊点与焊盘/引脚之间未形成电气连接
- 判定: 任何开路均为缺陷 (所有 Class)

### 8.3 少锡 (Insufficient Solder)
- Class 2: 焊料覆盖 < 焊盘面积 75%
- Class 3: 焊料覆盖 < 焊盘面积 100% 或焊点高度 < 端子厚度 50%

### 8.4 锡珠/锡渣
- 直径 > 0.13mm 的锡珠不允许 (Class 2)
- 任何松动的锡珠不允许 (Class 3)
